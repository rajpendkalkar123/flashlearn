# FlashLearn – Smart Flashcards & Quizzes ⚡📚

FlashLearn is a **Flutter-based learning app** that helps students and professionals create, organize, and practice **flashcards** and **quizzes**. With Firebase integration, your study materials are securely stored in the cloud and available across devices.

## 🚀 Features
- ✨ **Flashcards** – Create sets with term + definition  
- 📝 **Quizzes** – Multiple-choice questions with scoring  
- ☁️ **Cloud Storage** – Sync flashcards & quizzes via Firebase Firestore  
- 👤 **Profile Section** – Manage all your saved study sets  
- 🎨 **Modern UI** – Clean, responsive, and user-friendly design  
- 🔒 **Firebase Auth** – Sign in securely to save progress  

---

## 🏗️ Tech Stack
- **Frontend:** Flutter (iOS, Android, Web)  
- **Backend:** Firebase Firestore (Database)  
- **Auth:** Firebase Authentication  
- **AI Integration (Optional):** OpenAI API for auto-generating flashcards/quizzes

# FlashLearn – Smart Flashcards & Quizzes ⚡📚

FlashLearn is a **Flutter-based learning app** that allows students, professionals, and lifelong learners to create, practice, and store **flashcards and quizzes** in a simple and effective way. With Firebase integration, your study materials are always secure and accessible across devices.

---

## 📖 Use Cases
- 🎓 **Students** – Prepare for exams with flashcards & quizzes  
- 🧠 **Professionals** – Revise concepts and skills quickly  
- 👩‍🏫 **Teachers** – Share flashcard sets with students  
- 🌍 **Lifelong Learners** – Store and review knowledge anywhere  

---

## 🛡️ Security
- **Firebase Authentication** secures user accounts  
- **Firestore security rules** protect user data  
- **Private by default** – All personal content remains private unless shared
